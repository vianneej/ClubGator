# ClubGator Chat

Players can chat with other players in the same area. The main
campus map uses the room ID `campus`. Each location uses its
landmark ID, such as `location:library-west`.

Messages are stored at:
`chatRooms/{roomId}/messages/{messageId}`

Each message contains:
- `senderUid`: the sender's Firebase account ID.
- `senderUsername`: their saved username.
- `text`: the message, with a limit of 300 characters.
- `createdAt`: a timestamp generated by Firestore.

The chat shows the latest 50 messages, oldest to newest.
New messages appear automatically. When a player changes areas,
the app stops listening to the old room and opens the new one.

The player's current chat room is stored at `chatSessions/{uid}`.
It contains `roomId` and a server timestamp called `updatedAt`.
An account has one current room, so changing rooms in one browser
tab stops chat in other tabs viewing the previous room. Those tabs
can rejoin their own area.

Players must be logged in and have a completed profile to use chat.
They can only change their own chat session and read or send
messages in their current room. Messages must use their actual
account ID and saved username. Players cannot edit or delete
messages.

Room IDs must refer to the campus map or an existing landmark.
The app reports the player's room; this does not independently
verify their position in the game.

For now, chat is for groups in the same location. Private messages
and moderation tools can be added later.
